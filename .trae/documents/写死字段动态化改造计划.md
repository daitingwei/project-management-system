## 后续扩展方案（前端要扩展时）

当需要支持需求/文档/Bug等模块时：

### 1. 前端需要传 linkType
```js
this.$store.dispatch('setTempData', {
    projectCode: this.projectCodeCurrent,
    taskCode: this.code,
    projectName: res.data.projectName,
    linkType: 'requirement',  // 或 'doc', 'bug'
})
```

### 2. 后端改造（添加默认值兼容）

```go
// 只需要改这3处，添加默认值即可

// 1. LinkType
linkType := msg.LinkType
if linkType == "" {
    linkType = "task"
}

// 2. ActionType
actionType := msg.ActionType
if actionType == "" {
    actionType = "task"
}

// 3. 缓存key
cacheKey := msg.CacheKey
if cacheKey == "" {
    cacheKey = "task"
}
```

### 3. proto 添加字段（可选）
```protobuf
message TaskFileReqMessage{
  // ... 现有字段 ...
  string linkType = 11;  // 可选，后续前端扩展时使用
}
```
