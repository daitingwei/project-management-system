# Go版本对标Java版本完整计划 Spec

## Why
Go版本项目（project-project）是基于gRPC的微服务实现，Java版本（src）是完整的单体应用。需要全面对标Java版本，将Go版本缺失的功能全部实现或对齐。

## Impact

- **Affected specs**: 所有业务模块
- **Affected code**: 全部Go代码

## ADDED Requirements

### Requirement: 完善部门管理
实现部门删除、编辑、树形结构、成员管理等8个功能

### Requirement: 完善项目管理
实现归档、取消归档、退出项目、统计、报告等5个功能

### Requirement: 完善任务管理
实现标签、点赞、收藏、删除恢复等10个功能

### Requirement: 实现成员管理
实现邀请、移除、搜索等功能

### Requirement: 实现权限管理CRUD
实现权限的增删改功能

### Requirement: 实现登录认证
实现验证码、Token刷新、密码修改等功能
