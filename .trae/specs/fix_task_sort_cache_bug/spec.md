# 任务排序缓存Bug修复规格说明

## 问题描述
当用户调换任务位置后：
1. 数据库中的排序已经正确更新
2. 但前端界面没有正确反映变化
3. 点击任务详情并关闭后，界面显示错误数据（重复的任务）
4. 刷新页面后数据正常

## 根本原因分析
- 任务列表使用了**内存缓存**，排序更新后缓存没有清除
- 查看任务详情时可能触发了某些重新渲染逻辑
- 前端缓存策略导致旧数据被保留

## 影响范围
- 前端文件：
  - `前端/src/views/project/space/task.vue` - 任务列表主组件
  - `前端/src/components/project/taskDetail.vue` - 任务详情组件
- 后端文件：
  - `project-project/pkg/service/task.service.v1/task_service.go` - TaskSort 方法

## 需求说明
### 需求：任务排序后正确更新界面
#### 场景：任务排序成功
- **当** 用户拖拽任务调换位置
- **则** 数据库更新成功
- **则** 前端界面立即反映新排序
- **则** 查看任务详情后返回，不影响排序显示

#### 场景：任务详情关闭后
- **当** 用户查看任务详情后关闭
- **则** 任务列表不应重新加载旧数据
- **则** 当前排序状态应保持不变

## 待检查项
1. 前端是否有缓存机制导致数据不更新
2. 任务详情弹窗关闭时是否触发了不必要的列表刷新
3. 后端 TaskSort 接口是否正确处理了排序逻辑
4. 是否有乐观锁或版本控制机制缺失
